
# Sistema de Gestión de Inventario

Proyecto académico desarrollado en C# con Windows Forms y .NET Framework.

## Funcionalidades

- Gestión de productos.
- Gestión de categorías.
- Gestión de proveedores.
- Gestión de locales.
- Gestión de inventarios.

## Reportes LINQ

- Productos ordenados por nombre o precio.
- Productos con stock bajo.
- Productos agrupados por categoría.
- Cálculo del valor total del inventario.
- Productos agrupados por proveedor.

## Control de versiones

Se utiliza Git y GitHub para registrar cambios, trabajar con ramas y revisar modificaciones mediante Pull Requests.
